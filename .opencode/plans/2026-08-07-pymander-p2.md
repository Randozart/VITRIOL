# Pymander P2 — Injection + Tool

Date: 2026-08-07.

## 1. Goal

Wire Pymander (built in P1) into the running agent: doctrine injected into the
window the same way Hermetis knowledge is (selective context path), plus the
`pymander` opencode tool for the model to query/switch/author.

Rides the existing Copula plugin auto-inject machinery — no new injection
plumbing.

## 2. Scope

1. **Server endpoints** (`libvitriol/pymander.py` → expose via
   `hermetis_server.py`, or a small `pymander_server`): `/pymander/list`,
   `/pymander/search`, `/pymander/select`, `/pymander/active`, and aggregate
   `/pymander/context` that retrieves doctrine across a project's *selected*
   domains into a budgeted block for injection.
2. **Copula plugin** (`plugins/copula.ts`): a `pymander` tool (query + switch +
   list), and doctrine injection at session start (bounded, labeled
   `[Pymander doctrine]`) using the selected domains.

## 3. Evidence

- `plugins/copula.ts` already auto-injects via `/hermetis/context` on
  `chat.message` (line ~82). Pymander reuses the same block-inject path.
- `libvitriol/pymander.py:search()` + `get_selection()` exist (P1) — the server
  only needs thin wrappers + an aggregate context builder.

## 4. Design decisions

- **Doctrine block**: distinct label `[Pymander doctrine]` so injected doctrine
  is never re-ingested (plugin already skips `[Hermetis context]`/`[compaction
  capture]` labels — extend that skip list).
- Selection already per-project (`selection.json`, P1). Injection uses the
  project_id → selected domains → aggregate top nodes per domain under a token
  budget.

## 5. Tests

- Python: ingest + select domains, `/pymander/context` returns budgeted block,
  `/pymander/search` returns nodes, missing domain safe.
- Plugin: not unit-testable here (TS + opencode). Manual: doctor/inject path.
