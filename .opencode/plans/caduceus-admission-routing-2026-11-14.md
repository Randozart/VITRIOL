# Caduceus admission routing + Pi guarantees + Rust core (2026-11-14 20:05)

Operator: "Caduceus should really route better than this" (repeated 400/429/404
cascades), "guaranteeing it doesn't have bugs", and "high ROI for a Rust core
on stuff we keep fighting". Decisions: keep failing over to an owner's offered
alternatives **when they are free**; a context-overflow 400 **benches the whole
owner** for the stated pause.

## Production bodies this plan must kill

1. `400 … maximum context length is 180000 tokens … paused for 11 minutes.
   Requests under about 56 KB still go through` — a **key-level circuit** with a
   shrinking safe size, not just a per-request limit.
2. `404 … This model is not currently offered: moonshotai/Kimi-K2.6. Available
   models: MiniMaxAI/MiniMax-M2.7, deepseek-ai/DeepSeek-V4-Flash-0731,
   zai-org/GLM-5.3-Flash` — a stale catalog id per owner.
3. `429 … All credentials for model X are cooling down, reset_seconds: N` —
   gateway-side credential cooldown (invisible to headers).
4. Retry storm: each lane cooling on its own schedule, so a turn walks the whole
   pool one failure at a time; compaction then fails and the user resumes into
   the same wall.

## A. Owner-level admission state (`_shared/gateway-health.ts`)

Extend the shared facts file with:

```
pauses:  { <owner>: { until, safeBytes?, reason } }   // 400 key circuit
offered: { <owner>: string[] }                        // from 404 "Available models"
aliases: { <fullModelId>: <fullModelId> }             // learned remaps
```

Parsers (all fail-open, pure, fuzz-covered):
- `parseOwnerPause(body)` → `{ pauseMs, safeBytes }` from
  `paused for N minutes` and `under about N KB still go through`.
- `parseContextLimit` already covers both 400 wordings; `parseOverflowPromptTokens`
  covers `value=…` / `estimated … input tokens`.
- `parseModelNotFound` already returns `{ missing, alternatives }`.

Admission rules:
- A model is admitted iff: not invalid, not gateway-cooling, owner not paused,
  and `promptTokens + reserve <= min(declaredWindow, learnedLimit, safeBytes/4)`.
- Owner pauses are owner-wide (operator decision) and expire exactly as stated
  (`OFFICINA_OWNER_PAUSE_MAX_MS`, default 60 min, floor 1 min).
- Safe bytes are cleared on the next successful request for that owner.

## B. 404 → learn, remap, fail over (resilient-default)

On `model_not_found`:
- mark the exact lane invalid (6 h, already shipped);
- record the owner's offered list;
- build `owner/<alternative>` ids, keep those that are **free** (freeTier/free)
  and admitted, and remap the failed id to the best one (persist `aliases`);
- select it **in the same turn** if it fits; otherwise continue normal selection.

## C. Retry budget (`resilient-default`)

- `OFFICINA_CLOUD_RETRIES` (default **2**) per turn.
- Exhausted, or every fitting lane paused/cooling/invalid ⇒ **local** when it
  fits (262k); otherwise one actionable error (no `Resume` loop).
- `state.cloudRetries` resets on a successful message.

## D. Compaction always succeeds (small-lane)

- Summarizer chain filtered by admission (invalid/cooling/paused owners skipped,
  local always included).
- If nothing fits the full transcript: deterministically shrink the summary input
  (keep the newest ~80% of the largest available window, prepend a digest of the
  omitted prefix) and retry once. Never fail compaction for lack of fit.

## E. Pi guarantees

- Every production body above becomes a **golden fixture**; routing fixtures
  assert the admission decision (admit/skip/pause/remap/local) — `npm test`
  fails if a past incident can repeat.
- Provider-body property tests: parsers never throw, always yield a decision.
- Response-shape validation at the routing boundary (usage/finish reasons)
  becomes a typed error, not a crash.
- `/doctor`: gateway reachability, catalog/lane consistency, owner pauses,
  session format self-check.

## F. Rust core — Phase 1 (`vitriol-core/`, standalone crate)

Pure decision logic, parity-gated; pi stays the host (no provider/tool port):

- provider-error parsers (limit, overflow tokens, cooldown, owner pause,
  safe bytes, 404 alternatives);
- gateway-health marks + admission (`effective_window`, `lane_admitted`);
- budgets (billed-only) + token estimation;
- compaction threshold/digest + summarizer choice.

Integration: crate compiles as a library; TS adapters consume **golden vectors**
generated by `cargo test -- --nocapture` (committed) and, in Phase 2, a
unix-socket JSON-RPC sidecar behind `OFFICINA_ROUTER_CORE=rust`. Counsel
contracts on the pure admission/money math (debug/CI only).

**Parity gate (I2)**: with 0 peers, recorded-trace decisions must be identical
between TS and Rust; differences are enumerated and approved before either side
becomes authoritative.

## Invariants

- **I1** Admission is fail-open: a missing/corrupt facts file never blocks a
  healthy lane.
- **I2** Parity: recorded-trace decisions identical TS↔Rust for 0 peers.
- **I3** Owner pause is owner-wide and never shorter than the provider's stated
  window (up to the ceiling).
- **I4** A 404 never repeats for the same lane: invalid + remap persisted,
  visible in the ledger.
- **I5** At most `OFFICINA_CLOUD_RETRIES` cloud attempts per turn; the next step
  is local or a single actionable error.
- **I6** Compaction cannot fail due to size: it shrinks the input and retries.
- **I7** No new hot-path runtime checks in release; parsers are pure.
