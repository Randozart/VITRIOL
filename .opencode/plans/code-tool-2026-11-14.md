# `code` tool — verify + format by default (2026-11-14 12:05)

Operator request: "a code tool that verifies and formats by default, helping
the LLM write clean code", which should "also show the code and diffs".
Decisions: new explicit `code` tool; cheap gates per settle **and** praetor on
by default; prettier added so JS/TS formats on this host; `format` rewrites
files on disk.

## What already existed

- `format-gate`: formatter after every edit/write (ruff/prettier/gofmt/rustfmt/
  clang-format), one-shot tail notice. Enabled unless `OFFICINA_NO_FORMAT=1`.
- `diagnostics-loop`: per-file SYNTAX check after edits, failures as a tail.
- `praetor` integration: opt-in (`OFFICINA_PRAETOR=1`), validates a copy of the
  edited file, bounded diagnostics tail.
- `verify` extension: cheap tier gates (`tsc --noEmit`, `cargo check`,
  `cargo fmt --check`, `ruff check`, `go vet`, canaries) — on demand only.
- TUI: write/edit blocks rendered as generic key/value args; `result.details.diff`
  from pi's edit tool was dropped on the wire.

## Deliverables

### 1. `code` tool (`.pi/extensions/code-tool/`)
Model-callable, advisory, never blocks:

```
code({ action?: "all"|"format"|"verify", paths?: string[],
       tier?: "cheap"|"full", praetor?: boolean })
```

- default `all`: format (rewrites), then verify (syntax + cheap gates + praetor
  on the touched files); returns a compact `✓/⚠/✗` report + structured details.
- `paths` default = files edited this session (tracked from tool_result).
- `verify` includes: per-file syntax checks (shared `diagnostics-loop/diag.ts`),
  cheap/full gates (shared `verify` runner), praetor validate (extracted into
  `praetor/praetor.ts`).

### 2. Formatting correctness
- `format-gate/format.ts`: resolve formatters project-locally (walk up from the
  edited file for `node_modules/.bin/<cmd>`), then PATH; `rustfmt` edition from
  the nearest `Cargo.toml` (2024 here, 2021 fallback).
- `officina/package.json`: add prettier as a devDependency (lockfile updated).
- Outcomes recorded to `~/.vitriol/officina/toolchecks/<toolCallId>.json`
  (atomic merge; pruned) so the TUI can show per-call status.

### 3. Verification defaults
- Praetor enabled by default: `OFFICINA_NO_PRAETOR=1` off, explicit
  `OFFICINA_PRAETOR=0` off, otherwise on. Operator env flipped via
  `vitriol caduceus config set praetor on`.
- New `verify-on-edit` extension: records touched files + hashes on edit/write;
  after a settle runs cheap gates **once** when the file set changed, with a
  25 s budget and 10 s cooldown; injects failures only (bounded tail) and
  notifies on failures. Env: `OFFICINA_VERIFY_ON_EDIT=0`,
  `OFFICINA_VERIFY_BUDGET_MS`, `OFFICINA_VERIFY_COOLDOWN_MS`.

### 4. TUI — show the code and the diffs
- `tui/src/tui/diff.rs`: pure LCS line diff + unified formatter (tested).
- `markdown.rs`: `pub fn highlight_code(path, text, width)` (syntect reuse).
- `edit` blocks: unified diff (canonical `result.details.diff` when present;
  args-derived preview while running) with `+/-`/`@@` coloring.
- `write` blocks: highlighted content preview; overwrites also show a diff
  (file snapshotted at tool_start, ≤200 KB).
- `code` tool block: report lines colored by status.
- Checks footer on edit/write blocks from the facts file: `✓ rustfmt · ✓ syntax`.
- All tool output lines beginning `✓/✗/⚠` get green/red/amber.

## Invariants

- **I1** Every check is advisory; edits are never blocked.
- **I2** Clean runs are silent (zero injected tokens); failure tails are
  bounded and append-only (cache-safe, Rule 7).
- **I3** PATH-only formatter resolution is unchanged (parity for existing
  formatters); local-bin discovery only adds candidates.
- **I4** verify-on-edit runs at most once per settle, only when the touched
  file set changed, within budget/cooldown.
- **I5** Block/Full tool views never show raw unhighlighted write/edit code;
  diffs always use the shared `+`/`-`/`@@` semantics.
- **I6** `code format` is idempotent: a second run reports no changes.

## Tests / gates
Formatter resolution (local bin, editions), praetor enable matrix, verify-on-edit
trigger/throttle/signature, code tool (all/format/verify, idempotence, caps),
diff engine, highlight helper, TUI render smoke (write/edit/code blocks).
`npm test`, `npm run typecheck`, native build; `cargo test`, `cargo fmt --check`;
rebuild + install `~/.local/bin/officina`.
