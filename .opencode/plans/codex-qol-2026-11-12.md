## Goal

Adopt the Codex CLI conveniences the operator selected, in ten stages, one
commit each. No security-model changes to existing modes; everything new is
opt-in or read-only.

## Stages

1. **Remove `/mode` alias** (`agent-mode/index.ts:171`) — it shadows typing
   `/model`. The legacy `/mode plan` widget *parsing* stays (tests pin it).
2. **`/status` modal** (Rust TUI) — model + agent mode, ctx fill, cwd,
   session, permissions mode, profile (read from the routing-profile file),
   gateway/lane summary (read from `caduceus-state.json`), prefs summary.
   Local read-only modal in the help-modal family.
3. **Resume search** (Rust TUI) — typeable substring filter in the `/resume`
   picker; Esc clears the filter first, then closes.
4. **`$EDITOR` prompt escape** (Rust TUI) — Alt+E hands the terminal over via
   `suspend_external`, opens the composer draft in `$VISUAL`/`$EDITOR`
   (tmp file), loads the result back. Editor failure/cancel never loses the
   draft; non-TTY refuses with a note.
5. **Diff-first tool rendering** (Rust TUI) — edit/write tool outputs that
   look like a unified diff get `+` green / `-` red / `@@` muted line
   coloring. Non-diff output unchanged.
6. **`/review` extension** (pi) — `ui.select` presets: uncommitted diff /
   a commit / base branch (merge-base with main|master|origin) / custom
   instructions. The diff is gathered by git subprocess; the review turn is
   sent via `pi.sendUserMessage`; while the review turn is in flight,
   edit/write/bash tool calls are **blocked** (read-only invariant). The
   model returns a fenced `officina-review` JSON block; the extension parses
   it and writes `.officina/review.json` (versioned schema).
7. **Review findings modal** (Rust TUI) — `/review-findings` opens a j/k
   severity-colored list from `.officina/review.json`; Enter shows detail;
   missing file = honest hint. Read-only.
8. **Composer predictions** (pi + verify) — verify gains
   `.officina/verify-last.json` (last run summary). A `composer-predictions`
   extension listens for turn end and renders one advisory line via the
   belowEditor widget: failing gates → "fix the failing gates (/verify
   full)"; dirty tree + green gates → "commit the work"; else silent.
   `OFFICINA_NO_PREDICTIONS=1` kill switch. Never sends anything.
9. **Image paste** (Rust TUI) — Ctrl+V probes the clipboard
   (`wl-paste` under Wayland, `xclip` under X11, `image/png`/`image/jpeg`),
   saves to a temp file, shows `[img N]` chips in the composer; Alt+V clears;
   send attaches base64 `images` (caps: 8 MiB, 4 images). Failures are
   notices, never crashes.
10. **Bash sandboxing** (pi + Rust perms modal) — new `sandboxed` permissions
    mode: the permissions-guard `tool_call` handler rewrites bash commands to
    run under bwrap (`--ro-bind / /`, rw binds for cwd + /tmp, `--dev`,
    `--proc`, `--unshare-net` unless `OFFICINA_SANDBOX_NET=1`). Quoting via a
    tested helper. bwrap missing → transparent fallback + one warning.
    yolo/ask/readonly never wrap (golden test: command string byte-identical).

## Invariants

- **I1 default parity** — with no operator action, behaviour is unchanged:
  no `/mode` (parsing-only legacy), `/status`/findings modals are read-only,
  sandbox never wraps unless the `sandboxed` mode is selected, predictions
  never fire under the kill switch, hidden/routing prefs untouched.
- **I2 review is hard read-only** — during a review turn every edit/write and
  bash tool call is blocked by the extension (pinned by a tool_call test);
  findings are written only from the model's JSON block.
- **I3 findings contract** — `.officina/review.json` carries `version: 1`
  and snake_case fields (serde contract); the modal degrades honestly on
  missing/corrupt files (I6-style corrupt-safety).
- **I4 draft safety** — the `$EDITOR` escape never destroys the composer
  draft: editor spawn failure, non-TTY, and empty edits all restore the
  original text; the terminal returns to raw+alt+mouse state afterwards.
- **I5 paste safety** — only `image/*` clipboard data is attached; missing
  tools/oversized/failed reads produce notices; caps enforced; the pending
  images never hit the wire unless the prompt actually sends.
- **I6 sandbox golden** — in every non-sandboxed mode the rewritten command
  equals the original byte-for-byte; quoting survives single quotes, `$`,
  and newlines; `OFFICINA_SANDBOX_NET` defaults to network-off; missing bwrap
  degrades to the previous behaviour with exactly one warning per session.
- **I7 advisory predictions** — predictions never call `sendUserMessage` or
  mutate state beyond their widget line; no crash when verify-last is absent.
