# DEMIURGE — VITRIOL Lanes Arbiter — 2026-09-27

**Status**: APPROVED (owner, 2026-09-27). Port `8265` (82XX band; 65 = ADNY
gematria — the Demiurge usurps the Lord's number, while obeying laws he did
not write: the privacy gate is the Monad's boundary, the ascensus budget is
the measured spend). Home: `demiurge/` in the VITRIOL repo.

**Thesis**: the machine can only run so many simultaneous workflows locally.
Demiurge watches engine pressure and routes AI sessions/workflows across
CONFIGURED lanes — local first (free), connected nodes second (stateful KV
handoff), free cloud third, euro-capped paid cloud last. Quiet day = zero
cloud spend. "Infinite slots": every client believes it has a slot; Demiurge
decides where that slot materializes.

## Built fresh (knooppunt is stateless by design)

1. Lane registry loader + validation (M1)
2. Pressure poller: llama.cpp `/slots` + `/metrics` -> busy-ratio, queue
   depth, deferred tasks, t/s decay; active health probes; stale-downweight
3. Session affinity: `X-Session-Id` -> lane pin + TTL; headerless = local-only
4. Arbiter state machine: hysteresis high/low watermark, return-to-local,
   decision order local -> node -> zen-free -> ascensus -> queue local
5. KV handoff (M4): rsync spill dir over Tailscale pre-flip; node's lazy
   restore finishes; fingerprint gate forbids cross-model restore
6. Evaluator seam (M5): structured transformer (Jev-1.13-free via zen
   systemone custom client, or local mellum2 lane) replaces thresholds in
   the indecisive band only; heuristic always armed

## Decision order (heuristic v0)

1. local pressure < high-watermark -> local
2. overflow + session-aware + node healthy + fingerprint match -> node
3. overflow + privacy=safe -> zen-free
4. overflow + privacy=safe + latency-critical + budget -> ascensus paid
5. else -> queue local (visible wait estimate)

Privacy law: sensitive/confidential NEVER leaves local, fail-closed.
Budget law: paid forwards pass ascensusd single-writer check first.

  0 re-prefill (cross-machine version of the 745/755 Optane cert)
