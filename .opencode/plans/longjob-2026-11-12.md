- Origin: operator proposal — instead of hanging on long bash calls, the

## Behavior

Known long-runner bash commands (cargo, make, brievc, npm/pnpm/yarn,
cmake, go, gradle, mvn, pytest, rustc, clang/g++ build families) are
rewritten at the permissions-guard hook into **dispatch form**: the shell
forks the payload via `setsid`, returns in ~50 ms, and the agent sees a
dispatch line (job id + log path) instead of a frozen tool row. The
agent polls `bg_status`, uses `bg_wait` for a bounded wait, or ends its
turn — when the job finishes, the watcher **injects the result into the
session** (`pi.sendMessage(..., { triggerTurn: true })` when idle) and
fires a desktop notification.

Escape hatches: trailing `#fg` on the command forces foreground; global
kill switches `OFFICINA_NO_AUTOBG=1` (dispatch rewrite only) and
`OFFICINA_NO_LONGJOB=1` (the whole extension).

## Stages

1. **`longjob` extension** — pure rules module (`longjob.ts`: matcher,
   opt-out, rewrite, announce-once registry logic) + four tools
   (`bash_bg`, `bg_status`, `bg_wait <id> <max_s>`, `bg_kill <id>`) + a
   5 s registry poll that announces finished jobs exactly once. Jobs live
   in `~/.local/share/officina/longjobs/<id>/` (cmd, out.log, pid, exit;
   0600). Completion: notify-send + `triggerTurn` when pi is idle; when a
   run is active, notify now and inject on the next idle tick.
2. **Guard auto-dispatch** — the permissions-guard bash branch (stage 2
   of this plan, living beside the sandbox rewrite) rewrites known
   long-runners without `#fg` into dispatch form. `sandboxed` mode skips
   auto-dispatch (stays foreground-wrapped — bwrap + detached jobs
   deferred, documented). Dispatch responses tell the model the poll
   pattern explicitly.

## Invariants

- **I1 fail-open** — any longjob failure (spawn error, disk, registry)
  falls back to running the command foreground exactly as today.
- **I2 never-kill** — the watcher never terminates jobs; `bg_kill` is the
  only terminator and it is explicit. `bash_bg` may carry an optional
  `max_minutes` that kills at expiry — that too is explicit agent intent.
- **I3 no fabricated results** — the dispatch response says plainly the
  command was backgrounded and where the exit code will land; nothing
  pretends to be the command's output.
- **I4 heuristic precision** — only `LONG_RUNNERS` matches are rewritten;
  `#fg` always wins; heuristic miss = byte-identical today behavior.
- **I5 single-announce** — each job completion is announced to the session
  at most once (registry `announced` flag).
- **I6 parity** — `OFFICINA_NO_AUTOBG=1` reproduces today's bash behavior
  byte-for-byte.
- **I7 log hygiene** — job dirs/logs are 0600 under
  `~/.local/share/officina/longjobs/`, persisted for post-mortem.

## Interplay

- Verify gates are immune by construction: verify/fix-loop run gates
  in-process (`runVerify`), never through bash.
- `sandboxed` mode (codex-qol stage 10) skips auto-dispatch in v1;
  bwrap + detached-job composition deferred with an honest doc note.
- The hang-watchdog keeps watch over FOREGROUND calls only — after this
  lands there should be almost none.
