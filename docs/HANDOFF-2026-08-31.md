## Session-critical laws (learned the hard way)

1. **PTY-test any interactive claim.** Two "fixed" commits once shipped
   stale code because nothing exercised input. Harness:
   /tmp/pty_test.py pattern — fork a pty, run `vitriol officina`, write
   keystrokes, assert echo. Recreate if missing (tiny).
2. **One-way flow**: edits land in VITRIOL only. A reversed rsync once
   reverted committed files (recovered from HEAD).
3. **Provenance is enforced**: docs/PROVENANCE.md is the citation index;
   selfcheck §3b fails if a registered file loses its header. New ports/
   vendored files must be added there + get a header.
4. **jiti caches transpiled extensions** in /tmp/jiti — `rm -rf /tmp/jiti`
   when an extension change seems invisible.
5. pi build bugs found upstream: persistent extension overlays break
   keyboard routing even with nonCapturing (bugfix log, OFFICINA.md);
